Game dashboard: which review interaction?

Both share the same page shell (header, event list, player, timeline). They differ in how a human accepts or rejects a draft. Click one to select, then tell me in the terminal what's wrong.

A

Inline review (recommended)

One page. Select any event in the list, accept or reject in the detail panel. Keyboard: j/k next/previous draft, a accept, r reject, t enter time. The list filter "Drafts only" turns it into a queue without a separate screen. Same page serves auto mode: no buttons, just the log.

B

Focused review queue

A separate route. One draft at a time, large video, two buttons, a counter. Faster for a scorekeeper grinding through a game, but it is a second screen to build and the dashboard has to stay in sync with it.
